Integrações do Sistema

Permite clicar com botão direito em qualquer documento no Windows Explorer e escolher Enviar para > LiteParse.
Menu "Converter para..." Não Registrado
Adiciona ao menu de contexto do Windows as opções rápidas:
  • Converter para Markdown (.md)
  • Converter para Markdown com OCR
  • Converter para Texto (.txt)
  • Converter para JSON (.json)
Pré-requisitos do Sistema
LibreOffice Portátil (Isolado) Verificando...
Instalação 100% portátil em subpasta local (bin/libreoffice). Não modifica o Registro do Windows, não altera o PATH do sistema e não requer permissões de Administrador.
Python 3 & LiteParse Verificando...
Ambiente Python para execução do motor estendido do LiteParse.
Instaladores do Sistema Multiplataforma
Geração de pacotes prontos para distribuição com identidade visual da PGE:
  • Windows: Instalador NSIS .exe (com atalhos e SendTo)
  • Linux: Pacotes .AppImage e .deb
  • macOS: Pacotes .dmg e .zip
